# 换新电脑指南 — bookocr-kit（识别图书工具）

这个压缩包是把台式电脑上的「扫描书识别工具」搬到笔记本电脑用的。
工具本体是 `bookocr.py` 这一个程序 + 三份说明书（`SKILL.md` 给 agent 看、`spec.md` 给转写子代理看、`README.md` 给你看），不装数据库、不起服务，拷过去就能跑。

---

## 一、包里有什么、没什么

| 在包里 | 作用 |
| --- | --- |
| `bookocr.py` | 识别台程序，11 个子命令（init/prep/pull/aivision/patch/next/check/retry/chapters/status/pack） |
| `selftest.py` | 全链路自测：合成一本 12 页假书跑一遍，验证这台电脑装对了环境。跑完显示 `ALL PASS` |
| `simcheck.py` | 相似度小工具（质检辅助） |
| `SKILL.md` | agent 操作手册。拷到新电脑的 skill 目录，或直接把路径念给 agent 听 |
| `spec.md` | 转写规范，子代理干活前必读 |
| `README.md` | 给人看的说明书（功能、设置项、常见问题） |
| `config.json` | 全局设置（识别路线、每批页数、dpi、并发数、产出开关），**不含密钥** |
| `requirements.txt` | Python 依赖清单，只有 PyMuPDF、reportlab 两个包 |
| `apis.json.example` | API 三键模板，见下面第六节 |

| 不在包里 | 为什么 |
| --- | --- |
| `jobs/`（识别工程，台式机上 278MB） | 全是扫描页原图和书稿正文。《民法物权》577 页已经识别完并打包（txt / 插图版 PDF / KIT 图包都在台式机 `bookocr-kit\jobs\民法物权\output\`），笔记本上没有需要续跑的书；剩下两本是测试样本。程序 `init` 时会自动建 `jobs` 文件夹，不用拷 |
| `apis.json`（含明文 API key） | 你现在的识别路线是 `subagent`（走 agent 自己的额度），用不到这支 key。哪天切到 `aivision`（识图 API 直连）再按第六节填一次，省得 key 跟着压缩包在网盘/U 盘链路上裸奔 |

## 二、新笔记本三步装好

### 第 1 步：把包解压到一个**纯英文路径**

推荐和台式机保持一致：`C:\AIWorkSpace\`（解压后是 `C:\AIWorkSpace\bookocr-kit`）。
路径里别出现中文和空格，程序日志、pip 缓存对中文路径容易出问题。

### 第 2 步：装 Python 和两个依赖包

1. 到 https://www.python.org/downloads/ 下载 Python 3.10 以上（台式机用的是 3.12.7），安装时**一定要勾上 "Add python.exe to PATH"**。
2. 按 `Win + R`，输入 `cmd` 回车，敲这两行（第一行进目录，第二行装包）：

```
cd /d C:\AIWorkSpace\bookocr-kit
pip install -r requirements.txt
```

pip 下载慢就换国内镜像，同样一行命令：

```
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

不装 reportlab 也能跑，只是出不了「插图版 PDF」。

### 第 3 步：跑自测，确认这台电脑没问题

还是在 `cmd` 里：

```
cd /d C:\AIWorkSpace\bookocr-kit
python selftest.py
```

它会自己合成一本 12 页假书，把 init → prep → next → check → retry → chapters → pack 整条链路走一遍，跑完自动删掉临时工程。
最后一行输出 **`ALL PASS`** 就是好了；任何一步失败它会列出来，直接把这行报错发给 agent 就行。

## 三、让笔记本上的 agent 认识这个功能（二选一）

- **拷进 skill 目录**：新建文件夹 `C:\Users\<你的用户名>\.agents\skills\scan-book\`，把 `SKILL.md` 放进去（文件名保持 `SKILL.md`）。之后说一句「识别这本书」它就会自己找到手册。
- **不拷**：直接对 agent 说「打开 `C:\AIWorkSpace\bookocr-kit\SKILL.md`，照着做，识别 `D:\书\xxx.pdf` 这本书」。

这套手册是 agent 无关的：Qoder / ZCode / 其他能读文件、派子代理的 agent 都能执行；跑到一半换一个 agent 接着跑也行（先 `python bookocr.py status <书名>` 看进度）。

## 四、日常怎么用

跟 agent 说一句：**「识别这本书，PDF 在 D:\书\xxx.pdf」**。
产出在 `bookocr-kit\jobs\<书名>\output\`：`书名.txt`（纯文字）、`书名_插图版.pdf`、`书名_Kit图包.zip`（手机 App 导入首选，章表+正文+插图一个文件全带）。
传手机：优先 `adb` 直连（笔记本装了 adb 的话，pack 会自动推），没 adb 就微信/网盘发文件，App 书架「导入书籍」里选它。

## 五、App（读书搭子）源码在笔记本上怎么拿

工具在 GitHub 上，笔记本直接克隆，不用拷：

```
git clone https://github.com/Lwb1397111398/Studying-with-friend.git
```

编译 APK 还需要（笔记本上第一次建环境要装）：JDK 17、Android SDK（台式机装在 `C:\Users\jingyue\AppData\Local\Android\Sdk`，笔记本用 `C:\Users\<你的用户名>\AppData\Local\Android\Sdk`）。
两个已知坑：

1. `GRADLE_USER_HOME` 必须指向英文路径，中文路径会让测试 worker 类加载失败。
2. 签名钥匙 `android\keystore\app.keystore` **不入 GitHub**。笔记本不拷这把钥匙也能出 debug 包、能装；但要出能覆盖安装的 release 包，得把钥匙从台式机单独拷过去（走 U 盘，别走网盘），或者让 GitHub Actions 从仓库 secret 里注入。

推 `main` 会触发 GitHub Actions 自动构建并发布 Release，手机「检查更新」就能装新包——这是设计好的链路，知道就好。

## 六、哪天要用「识图 API 直连」路线（可选）

把 `apis.json.example` 复制一份改名成 `apis.json`（去掉 `.example`），填三个键：`base_url`、`api_key`、`default_model`。
再把 `config.json` 里的 `"route": "subagent"` 改成 `"route": "aivision"`。

注意：

- `apis.json` 是密钥文件，**别提交到 GitHub、别发进对话**（台式机的仓库 `.gitignore` 已经把它排除了，笔记本克隆下来同样不会被传上去）。
- 程序还会尝试读 `C:\Agent\AImanager\ai-apis.json` 当备用配置——那是 Agent Manager 的本机档案库，笔记本上没装就没有，不影响 `subagent` 路线。

## 七、隐私提醒（和台式机上一样）

- `jobs/` 里的扫描页原图和书稿正文**不进仓库、不进网盘共享目录**。仓库 `.gitignore` 已排除，但自己在 U 盘/微信里传文件时留意别顺手传到公开位置。
- 产出只存在本机；传手机用的是你自己的微信或 adb。

## 八、2026-11-01 起：换电脑走 GitHub，压缩包流程留作断网备用

bookocr-kit 现在有自己的 GitHub 仓库：`https://github.com/Lwb1397111398/bookocr-kit`。权威源是台式机 monorepo（`Studying-with-friend` 仓库）里的 `bookocr-kit/` 子目录——改动先落 monorepo，再由它推送回本仓库。新电脑直接克隆，不用再打压缩包：

```
git clone https://github.com/Lwb1397111398/bookocr-kit.git
cd bookocr-kit
pip install -r requirements.txt
python selftest.py
```

笔记本上已有的克隆不用动，直接 `git pull` 就能拿到最新（2026-11-01 的同步是在笔记本 12 个提交之上叠加的，历史没有重写）。

规矩：**不要直接在本仓库提交代码**——台式机每次同步会以 monorepo 的 kit 内容为准整体覆盖。要改工具，先在台式机 monorepo 里改（或把改动报给台式机合并），再由它同步过来。
