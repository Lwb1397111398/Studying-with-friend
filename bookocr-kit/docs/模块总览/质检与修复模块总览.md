# 质检与修复模块总览

## 模块职责

回答两个问题：这批转写合不合格（check），这本书哪些页的正文不可信（qa）；并把点名的坏页交给视觉模型按页重识别（reocr），其余页一个字不动。

## 运作流程

1. `cmd_check <书名> <批号>`：页标记对账（缺页/多页/乱序）、U+FFFD 硬判、页均字数阈值（默认 100）、可读字符占比（中文+拉丁+数字 ≥50%，避免德文书目/索引被误判）、图台账 page 范围。通过 → `status=done`；不过 → `failed` + 原因。
2. `cmd_qa <书名>` 逐页体检（只读，不改批文件）：
   - 从批文件取该页段落；从 PDF 重新跑 `_page_lines` + `_detect_fig_bands`，数「图示乱码区」；已 `reocr` 的页跳过 band 判定（正文已是看图转写）；
   - 坏字 = `_fix_ocr_text` 能改的字数 + `＠｛｝｀＼｜〜�` 计数；繁体 = `_TRAD_ONLY` 命中数；引号 = 段落内 `“`/`”` 不等；短行/无句读排除章标题与二级标题（`SUBHEAD_RE`）；
   - 分数 = 3×图示区 + 2×坏字 + 2×繁体 + 引号 + 0.5×短行 + 0.5×无句读；
   - 写 `qa_report.json` / `qa_report.md`，打印 top 页与建议命令（分数 ≥6 的页，pull 书自动带 `--exact`）。
3. `cmd_reocr <书名> --pages … --exact`：
   - 目标页渲染缺的图 → 视觉 API 逐页识别 → `reocr/pNNNN.json`（已存在则复用，`--force` 才重跑）；
   - 重建涉及的批：**任何页只要有 reocr 结果就优先用结果**（即使不在本次 --pages），其余页现场 `_pull_page` 重抽（`--exact`）；不加 `--exact` 则整批 10 页全部视觉重识别；
   - 重建后 `cmd_check`（共享 manifest，避免 done 被旧台账覆盖回 assigned），清 `thin_pages/needs_vision`，删 `.stitched.json`，重置 chapters/packed。
4. `cmd_patch`：对整页大图的 thin_pages 派视觉补描述（pull 路线图版页）。

## 入口文件

- `bookocr.py`：`cmd_qa`、`cmd_check`、`cmd_reocr`、`cmd_retry`、`cmd_patch`、`_pull_page`（复用）、`_aivision_page_retry`
- 产物：`jobs/<书名>/qa_report.json|md`、`reocr/pNNNN.json`、`backup-reocr-<ts>/`

## 对外接口 / 被谁调用

- CLI：`qa`、`check`、`reocr`、`retry`、`patch`
- `cmd_pull`/`cmd_aivision` 内部调用 `cmd_check`；`cmd_pack` 读取 `needs_vision`/`thin_pages` 做拦截。

## 依赖的上游模块

文字层拔取或视觉识别（提供批文件）；下游是切章打包。

## 关键数据结构

- `qa_report.json`：`{name, pages:[{page,chars,score,bands,open_bands,fig_ph,bad,trad,quote,short,noterm,sample}]}`
- `reocr/pNNNN.json`：`{page,body,notes,figs,model,ts}`
- manifest：`batches.*.needs_vision`、`batches.*.thin_pages`

## 已知坑与约束

- `--exact` 只对 `manifest.route=pull` 的书开放；视觉路线没有本地文字层可沿用，先 `pull` 或去掉 `--exact`。
- 重建批时必须给 `cmd_check` 传共享 manifest（`m=m`），否则 check 写的 `done` 会被下一轮的旧台账覆盖。
- `qa` 的分数是「可疑度」不是判决：索引页、目录页、表格页天然短行多/无句读，别追 100% 清零。
- 图版页（thin_pages >30% 页面被大图占据）不要用文字层硬转，走 patch 或 reocr。
- 已 reocr 的页再跑 `--pages` 别的页时，旧结果必须保留（代码已按「有结果就用结果」处理）。
