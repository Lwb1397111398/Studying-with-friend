# 切章与打包模块总览

## 模块职责

把转好的批文件切成手机 App 能直接用的章表，给 pull 图补语义，最后产出 txt、插图版 PDF、KIT 图包三件套。

## 运作流程

1. `cmd_chapters <书名>`：
   - `collect_book` 汇总所有 done 批的正文（按 `〔页N〕` 分段）；
   - 识别章标题（`CH_NUM_RE`：第X章/编/部/篇/卷/回/次）、节标题（`SEC_NUM_RE`：第X节/讲）、前置/后置词族（`CH_WORD_FRONT/BACK`，空白归一匹配——「索 引」「主要参考书目」「条文索引」带空格/带修饰词都能认）；
   - **引述目录块防护（两档）**：同页 ≥2 个章级候选时，页内有 ≥40 字正文长行 → 正文引述法典编章（《不当得利》p36-37 引《民法典》编章实录），整页候选全剔；无长行 → 编扉页形态（民法总论 p30/p102/p404/p524 实录），只剔章级简目候选、保留「第X编」真编头；
   - 同页排序章（lv1）先于节（lv2）；前置块标 `FRONT`、目录标 `TOC`、正文标 `BODY`、附录/索引/参考书目标 `BACK`；
   - 与目录页条目逐条对账（difflib 相似度），产生 `toc_miss`/`gap`/`thin` 疑点，写 `chapters_review_task.txt`；
   - `--apply <裁决文件>` 吸收 ADD/DROP/RENAME/IGNORE（RENAME 修烂尾章名：旧名前 12 字组 key、新名=完整章名，锚=新名前 8 字自动重算；分隔符=带空格竖线，id 含裸竖线也安全）；`--no-review` 只记台账不拦 pack；结果存 `manifest.chapters`。
2. `cmd_figdesc <书名>`：
   - 待办 = `manifest.figures` 中 `desc == PULL_FIG_DESC` 的图；
   - 按 `rect`（比例坐标）从 PDF 直接 `get_pixmap(clip=…)` 裁小图 → `figures/<id>_p<页号>.png`；
   - 极扁横条（高 <48px 或高宽比 <0.06）判为装饰线/表格线，跳过识图；
   - 其余并发调视觉 API，返回 `{title,desc,kind}` 写回台账；失败重试一次，413 时降 dpi 重裁。
3. `cmd_pack <书名>`：
   - 拦截：未切章、thin_pages 未 patch、needs_vision 未复核、占位图未补语义、**未过智能校对**（`_proofread_coverage` 按 manifest.proofread.pages 覆盖判定；旧工程凭 `proofread/changes.json` 兜底；可 `--force`）；
   - 生成 `output/<书名>.txt`：头部写章界元数据块（App 识别后按章表直入），正文把 `〔图：…〕` 占位行替换成补好的图题+描述；
   - 生成 `<书名>_插图版.pdf`（reportlab 可用时，把原图嵌回对应页）；
   - 生成 `导入这个_<书名>_Kit图包.zip`（文件名带「导入这个」标记=手机导入目标，防与 txt/插图版 PDF 混淆）：`kit.json`（章表+图清单）+ `book.txt` + `figures/*.png`；
   - 写 `report/spotcheck.md`（5 页抽样对照）+ adb 直推手机（无设备只提示）。
4. `cmd_done <书名>`（归档，属工程与状态模块的目录搬运，但闸门语义在此）：疑点未裁决不归档（--force 放行）→ 未打包先补 pack → 清页图 → 移入 `已识别/<书名>/`（成品根部 + 工程/ + 原书 PDF）。

## 入口文件

- `bookocr.py`：`cmd_chapters`、`cmd_figdesc`、`cmd_pack`、`cmd_done`、`_proofread_coverage`、`collect_book`、`_aivision_figure`
- 产物：`识别中/<书名>/output/`（归档后 `已识别/<书名>/`）、`chapters_review_task.txt`、`figures/`

## 对外接口 / 被谁调用

- CLI：`chapters`、`figure-desc`、`pack`
- 依赖质检模块清空 `needs_vision`/`thin_pages` 后才能打包。

## 关键数据结构

- `manifest.chapters`：`[{t:标题,p:页,lv:1|2,r:FRONT|BODY,a:目录对账名}]`
- `manifest.figures`：`[{id,page,rect,kind,title,desc,from_pull,w,h,file}]`
- `kit.json`：`{title, chapters:[…], figures:[…]}`

## 已知坑与约束

- `figure-desc` 之后**不能再跑 pull**：pull 重建 figures 会把语义退回占位。
- `reocr` 会重置 chapters/packed，重识别后必须重跑 chapters 再 pack。
- 章疑点里的 `thin` 多是「章标题独占一页」的正常排版，IGNORE 即可；`toc_miss` 多是目录列到「节」而程序只把「章」当章，别盲目 ADD。
- 插图版 PDF 依赖 reportlab；没装则 txt/zip 照出。
- **目录样式**：目录条目页码有「裸数字」与「（页码）」两种形态（民法研究系列简目用后者），`TOC_TITLE_RE`/`TOC_ENTRY_RE` 已兼容；若新书目录标题另有新样式（如「凡例」），目录页会漏识别 → 目录行被切成假章，先查这两个正则。
- **判废图要同步删批占位行**：判废只删注册表条目，批文件里的「〔图：第N页插图K〕」占位行会残留，pack 时因注册表无对应图而原样进 txt（有图题无图）；修法=删批占位行后重 pack。
- **manifest.src_pdf 是绝对路径**：换目录名/换电脑后旧路径失效，重打包/重识别/补图描述会崩；修法=把 src_pdf 改到当前 PDF 位置（**别 glob '*.pdf' 取第一个**——归档根部还有旧插图版 PDF，取「非插图版」那份，2026-11-21 实录）。
- **章首页大字标题是文字层烂行重灾区**：王泽鉴体系书的章首标题页（大字居中）文字层常识别成乱码（「弟－早 六人一立…」），正则切不出章头 → 下一个章头前的全部正文挂进错名章。修法=照原书页图手改批文件那 1~2 行（数据修复），章名烂尾用 RENAME 裁决补全；`reocr --exact` 视觉重识别该页是备选（烧额度）。
- **z-library 来源 PDF 尾部有 [General Information] 元数据页**（书名/页数键值行）：pull 层已自动改空白占位（2026-11-21）；存量书批文件里还有的，手工把〔页N〕块改成〔空白页〕即可。
