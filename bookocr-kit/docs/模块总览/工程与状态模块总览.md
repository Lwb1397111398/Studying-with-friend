# 工程与状态模块总览

## 模块职责

三文件夹工作区（待识别/ → 识别中/ → 已识别/）：建工程、多进程渲染页图、记录批次与进度，保证任何命令中断后都能从 `manifest.json` 接着跑；`auto` 调度器负责「有书续跑、没书开新」。

## 运作流程

1. `cmd_scan`：扫 `待识别/*.pdf` → 逐本 `_init_job`（建工程+切批）→ `cmd_prep` 渲染（pull-only 路线免渲染）→ 不动源 PDF。
2. `cmd_auto`：调度器——`识别中/` 有未完成工程就 `_advance` 续跑（subagent 输出领批任务卡后停；pull/aivision 自动跑完），没有就从 `待识别/` 取下一本 init+prep；识别完自动 `_finish_pipeline`（qa→reocr→proofread→chapters→pack→done）。
3. `cmd_done`：归档——未打包先补 pack → 清页图+重置 `rendered` → 原书 PDF 从 待识别/ 移入（别处拷贝）→ 工程整体移到 `已识别/<书名>/工程/`、成品拍平在 `已识别/<书名>/` 根部 → `manifest.archived` 记时间。
4. `cmd_clean [--apply]`：删页图释放磁盘（dry 先报大小）；同步清 `manifest.rendered`，prep 会重新渲染。
5. `_init_job <书名> --src <PDF>`：读 config → 建 `识别中/<书名>/` → 按 10 页切批 → 写 manifest → 打印下一步（`cmd_init` 与 scan/auto 共用）。
6. `cmd_prep <书名> [--pages a-b]`：**多进程**渲染页图（`_render_span` 顶层函数每进程独立开 PDF，≥8 页才并行，页级 try 防单页炸整段；fitz 异常必须转 str 否则无法跨进程 pickle），更新 `manifest.rendered`；已有页不重复渲染。
7. `cmd_status`：打印批状态计数 + **流水线四步完成度**（识别 n/m → 校对✓(N处) → 切章✓(N章) → 打包✓，✗=还没跑）。
8. 每条命令都通过 `load_manifest/save_manifest` 读写 `manifest.json`；main() 入口先 `migrate_legacy_jobs()`（旧 `jobs/` 自动改名 识别中/，带 PermissionError 重试）+ `ensure_dirs()`。
9. `resolve_job`/`normalize_bid`：书名与批号解析；`resolve_job` 同时认 `识别中/<书名>` 与归档后的 `已识别/<书名>/工程`。

## 入口文件

- `bookocr.py`：`cmd_scan`、`cmd_auto`、`cmd_done`、`cmd_clean`、`_init_job`、`cmd_init`、`cmd_prep`、`_render_span`、`cmd_status`、`load_manifest`、`save_manifest`、`resolve_job`、`_job_states`
- `kitpaths.py`：INBOX/JOBS/DONE 三个目录唯一定义处、`migrate_legacy_jobs`、`ensure_dirs`
- `config.json`：route/pages_per_batch/dpi/aivision_workers/chapter_review/output；可选 dir_inbox/dir_jobs/dir_done

## 对外接口 / 被谁调用

所有子命令都依赖本模块；`manifest` 是唯一进度权威来源；stitch/dispatch/check_ready/simcheck/proofread 均 import kitpaths 取目录。

## 关键数据结构

`manifest.json`：
```json
{
  "name": "民法总则-王泽鉴2022", "src_pdf": "…", "npages": 630,
  "dpi": 200, "color": false,
  "pages": [{"image": "images/0001.png"}],
  "rendered": [1,2,…],
  "batches": {"b001": {"pages":[1..10], "body":"batches/b001.txt",
              "notes":"…", "figures":"…", "status":"done",
              "needs_vision":[…], "thin_pages":[…]}},
  "proofread": {"pages":[已校页], "fixed": 修复数, "at": "时间"},
  "chapters":[…], "figures":[…], "packed": true, "archived": "归档时间"
}
```

## 已知坑与约束

- **书眉 `furniture` 在全书写入，reocr --exact 重抽非目标页时要用它**，否则书眉会重新混进正文。
- 多个 bookocr 进程同时跑会争「台账锁」并超时；批量处理请串行。
- 三个工作文件夹已 gitignore，不随 kit 拷贝走；换电脑重新识别。
- 不要手工改 `manifest.json` 的 batch 状态，跑 `check`/`retry` 更安全。
- **Windows 下刚写完的目录 rename 可能被索引服务瞬时占用**：迁移与任何目录改名都要带重试；子进程异常必须转 str（fitz 异常内嵌 swig 句柄不可 pickle，实测炸掉整段渲染结果）。
