## 统一工作循环（每期相同）

1. `python dispatch.py <书名> 3` 发 3 张任务卡（卡落 `识别中/<书名>/prompts/`）。
2. 一条消息并行派 3 个子代理，prompt 固定：「先 Read 任务卡文件，严格按卡执行，三件套用 Write 落盘，只回报一行统计」。
3. 子代理回来后 `python check_ready.py <书名>` 幂等质检；失败批 `retry` + 重派（prompt 附失败原因）；同批连续 2 次不过 → 停手记台账。
4. **调度策略（2026-11-19 实测修正）**：`auto` 收尾（qa→reocr→proofread→chapters→pack）全程持全局锁，期间所有书的 dispatch/check 冻结约 30~40 分钟。因此**先把 6 本书的批全部转写完（3 并发全程满载），最后再逐本串行跑 `auto --book <书名>` 收尾**——转写期绝不中途收尾，锁冻结零浪费。第3册例外：其收尾已在本轮跑了（qa+reocr+proofread 中）。
5. 收尾停在「章界疑点待裁决」时派纯文本裁决子代理 → `chapters --apply` → 重跑 auto。
6. 归档后更新 `..\图书\识别进度.md` 总览表与本文件勾账。
