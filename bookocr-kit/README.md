# bookocr-kit — 纸质书识别台

把**扫描版 PDF**（影印书、扫描书）转写成能导入手机阅读 App 的书稿：`书名.txt`（微信传手机直接导）+ `书名_插图版.pdf`（原图嵌回，App 自动显示插图）。

**三个文件夹，一眼看清书走到哪一步**（kit 目录下，首次运行自动创建，旧版 `jobs/` 会自动改名为「识别中」）：

| 文件夹 | 放什么 |
| --- | --- |
| `待识别/` | 老板把扫描版 PDF 丢进来（想识别的书全丢这里） |
| `识别中/` | 正在识别的书（每本一个工程文件夹，进度记在台账里，断点续跑、换 agent 接着跑都不重来） |
| `已识别/` | 识别完成的书（每本一个同名文件夹：成品三件套 + 原书 PDF + 工程/） |

**多本书的推荐用法**：把一摞 PDF 丢进 `待识别/`，然后对 agent 说一句「按 SKILL.md 识别待识别文件夹里的书」。agent 会 `scan` 登记全部书目 → `auto` 逐本推进：识别中有书就续跑（哪怕今天只识别到 60 页额度用完，明天换一个 AI Agent 说同样的话就能低成本接着跑），没有就取下一本；一本书识别完自动走完 体检→校对→切章→打包→归档，成品出现在 `已识别/<书名>/` 文件夹根部。

**两种识别模式**（kit 目录 `config.json` 的 `route` 键选，默认 AI 逐页看）：

- **AI 逐页看**（`subagent`，默认）：真 AI 一页一页看图转字，断句、脚注、表格都干净。子代理路线用你所在 agent 的额度（ZCode / Qoder / 反重力等都能跑，见下）；`aivision` 变体改为直连你自己配的识图 API，10 页约 23 秒。
- **高效率看**（`pull-first` / `pull-only`）：很多影印书底子里藏着出版社级文字层，程序直接拔出来整理——分钟级、零 AI 费用、零幻觉；只有拔不动的批才让 AI 看图。**注意：扫描件的 OCR 文字层质量参差**（同一本书里可能混着干净页和整页繁体字、形近错字、图示乱码的页），pull 之后必须跑一次 `qa` 逐页体检，按报告用 `reocr --exact` 只重识别坏页（详见下方命令表与 SKILL.md）。

识别完程序自动**切章对账**：封面/版权/各版序言/作者简介/目录/正文章/附录各自成章，并与书的目录页逐条核对，拿不准的少数疑点派 AI 裁决。打包出的 txt 头部带「章界元数据块」——**手机 App 导入时读到它就直接按这份章表分章，不再自己猜**（章节切错的根治方案）。

正文只写进文件、不占对话记忆——一本 300 页的书，主对话只花一万多 token。

## 换新电脑：三步就能用

1. **装 Python 3.10+**（python.org 下载，安装时勾选 Add to PATH），然后：
   ```
   pip install -r requirements.txt
   ```
   （只有 PyMuPDF 和 reportlab 两个包；不装 reportlab 也行，只是没有插图版 PDF。）
2. **让 agent 认识这个功能**（二选一）：
   - 把 `SKILL.md` 拷到 agent 的技能目录（ZCode：`C:\Users\<你>\.agents\skills\scan-book\`）；
   - 或者不拷，直接对 agent 说：「打开 bookocr-kit/SKILL.md，照着做，识别 D:\xxx.pdf 这本书」。
3. **开工**：把扫描版 PDF 放电脑任意位置，对 agent 说：「识别这本书，PDF 在 D:\...」。

> 整个 `bookocr-kit` 文件夹随身拷走（U盘/网盘）即可，识别工程（jobs/）留在各电脑本地，不用拷。

## 日常怎么用（本机已装好 skill）

**多本书（推荐）**：把 PDF 全丢进 `待识别/`，跟 agent 说「按 SKILL.md 识别待识别文件夹里的书」。识别中的书进度都在台账里，中途停了、换 agent、换电脑，再说同样的话就接着跑（done 的批和章节裁决不会重来）。

**单本书**：跟 agent 说一句就行：**「识别这本书，PDF 在 D:\书\xxx.pdf」**。
识别完 agent 会汇报产出路径和章节情况。手机导入传 `导入这个_书名_Kit图包.zip`——**文件名带「导入这个」的就是它**（章表+正文+插图一个文件全带，App 里插图原位显示）；只要文字就传 txt。书架「导入书籍」→ 选文件，App 自动按电脑侧章表分章，完事。

**防漏步闸门**：一本书没过智能校对（proofread）、没切章对账，pack 会直接拒绝打包（`--force` 才放行并大声警告）；`status` 里能看到「识别 → 校对 → 切章 → 打包」流水线哪一步没跑。识别完的书跑 `done` 归档：清页图、移进 `已识别/<书名>/`。

## 想白嫖其他 agent 的免费额度？

可以。这套工具**agent 无关**：spec.md（转写规范）自包含、批文件全落盘、SKILL.md 不绑定任何一家。Qoder / 反重力等定期送额度的 agent，直接对它说「打开 bookocr-kit/SKILL.md 照做」就能干活；跑到一半换一个 agent 接着跑也行（先 `status` 看进度）。注意各家子代理并发上限不同，SKILL.md 里写了试水方法。

## 设置（kit 目录 config.json，改完对之后 init 的新书生效）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `route` | `subagent` | `subagent` AI 逐页看（子代理）/ `aivision` AI 逐页看（识图 API 直连）/ `pull-first` 先拔文字层拔不动再视觉 / `pull-only` 只拔文字层 |
| `pages_per_batch` | 10 | 每批页数 |
| `dpi` | 200 | 页图渲染精度 |
| `aivision_workers` | 5 | 识图 API 并发数 |
| `chapter_review` | true | 章界疑点是否派子代理裁决（无疑点的书自动跳过） |
| `output` | `["txt","pdf","zip"]` | 产出物开关（zip=KIT 图包：章表+正文+插图一个文件，App 直入图文混排） |
| `junk_chars` | （无） | 校对垃圾字黑名单**追加**字（内置清单：勹＄竺叩＼｜｀〜｛｝卩〓），新书出新垃圾字写这里，不用改代码 |
| `dir_inbox` / `dir_jobs` / `dir_done` | 待识别 / 识别中 / 已识别 | 三个工作文件夹的名字（想换名字改这里） |

## 文件夹里都是什么

| 文件 | 干什么 |
| --- | --- |
| `bookocr.py` | 识别台程序（十八个子命令：**scan 登记 待识别/**、**auto 多书调度**、init 建工程 / prep 多进程渲染 / pull 文字层拔取 / aivision 视觉 API / patch 图版页补描述 / next 发任务 / check 质检（含跨页断段预警）/ retry / **qa 逐页体检（--fix 一键修）** / reocr 按页重识别 / **proofread 智能校对** / chapters 切章对账 / status 流水线进度 / pack 打包 / **clean 清页图** / **done 归档**） |
| `kitpaths.py` | 三个文件夹（待识别/识别中/已识别）的唯一定义处 |
| `SKILL.md` | agent 的操作手册（agent 无关：触发词、省 token 铁律、流程、故障处理） |
| `spec.md` | 转写规范（子代理干活前必读：怎么转字、图表怎么处理、三个输出文件） |
| `config.json` | 全局设置（上表；无密钥，随 kit 走。可选键：`junk_chars` 追加校对垃圾字黑名单、`dir_inbox`/`dir_jobs`/`dir_done` 改三个文件夹的名字） |
| `待识别/ 识别中/ 已识别/` | 三文件夹工作区（每本书一个工程：页图、批次正文、台账、产出），已 gitignore 不进 GitHub |

## 常见问题

- **书稿内容会上传到网上吗？** 不会。三个工作文件夹（待识别/识别中/已识别）已被 gitignore，产出只存在本机；传手机用的是你自己的微信。
- **识别到一半中断了怎么办？** 没关系，对 agent 说「继续识别」，或直接 `python bookocr.py auto`——识别中有书就从断点接着跑（换 agent、换电脑都一样），完成的页和章节裁决都不会重来。
- **识别完想腾硬盘？** `python bookocr.py clean <书名> --apply` 删页图（几百 MB，正文/台账/成品/裁图不动）；或归档时自动清——`python bookocr.py done <书名>` 把书移进 已识别/ 时顺手删页图。
- **某几页糊得厉害？** 先 `qa <书名>` 看逐页报告（分数越高越可疑），按报告点名页跑 `reocr <书名> --exact --pages …` 用视觉 API 重识别，其余页不动；整页繁体字、图示乱码、双栏索引被拼成一段，都属于这类。
- **图和表格呢？** 表格转成文字表格插在原位；真图按精确坐标裁出原图，打进 KIT 图包 zip（App 导入后插图原位显示），txt 里在图的位置留一行图题+描述。pull 拔的书图题先是「第N页插图」占位，跑一次 `python bookocr.py figure-desc <书名>` 让视觉 API 逐图补图题和描述。
- **要花 AI 额度吗？** AI 逐页看模式逐页烧（子代理走对话额度、aivision 走识图 API 额度）；高效率模式几乎不花（文字直接拔，只有个别整页大图让 AI 写一句描述）。
- **章节会切错吗？** 电脑侧切完还和目录页对账，疑点让 AI 裁决；txt 带着章表进手机，App 照单分章不猜。真不满意，App 导入确认页里还能改名删章。
- **整页都是一张图（图版页）的书怎么办？** 程序把这类页记下来（thin_pages），正文写占位，用 `patch` 命令只让 AI 看这几页补图描述，不连累其他页。
