# 转写规范（识别书页图片时必读）

你的任务：把一批书页图片转写成纯文本。这本书是纸质书的扫描/影印版，最终在手机阅读 App 里阅读。

## 工作方式硬约束（违反 = 白烧额度）

- **每张页图最多 Read 一次**，直接整页读、整页转。实测整页直读的准确率（与出版社文字层比对相似度 0.98+）不低于任何放大方案。
- **禁止裁剪、放大、拼接图片**：不要用 Bash/PIL 生成任何衍生图（切条、裁局部、调对比度），不要重读同一张图超过一次。
- **只读任务卡列出的页图**，不读批次范围之外的其他页图；除 spec 外不要读别的文档。
- 全批应在 **约 15 次工具调用** 内完成（读 spec 1 次 + 每页读 1 次 + 写 3 个文件）。明显超出说明工作方式错了，停下来照规范重来。

## 每页的固定格式

- 每页正文的第一行写页标记：`〔页N〕`（N = 图片文件名里的页号，如 `0061.png` 就是 61）。整行只有这一个标记，不跟其他文字。
- 标记行下面写这一页的正文。段落之间空一行。
- 一段就是一段，不要把一个自然段拆成多行——每段一行写完。

## 转写原则

1. **忠实转写是第一原则**：逐字照录，不概括、不改写、不遗漏、不添油加醋。
2. **个别字词辨认不清时**：根据上下文推断补写，保证语句通顺、原意不变。不要留 `□`、不要写「（此处不清）」、不要用问号占位。
3. **忽略不转**：页眉、页脚的页码、水印、装订线阴影、馆藏章。
4. **标题**：章标题（如「第三章 合同的成立」）和节标题（如「第二节 要约」「一、要约的概念」）照原样单独成行转写，它们是后续自动切章的依据，一个都不能丢。
5. **脚注**：页脚的小字注释（常带 ①②③ 或数字编号）不算正文。这一页有几条脚注，就往脚注文件里写几行，每条一行，保留原编号（如 `① 王泽鉴：《民法思维》，北京大学出版社2009年版，第35页。`）。正文里不要插入脚注引用记号。
6. **表格**（页面上的表格）：转成纯文字表格——每行一条记录，用「列名：值；列名：值」或对齐的多行文本，保证信息完整可读。
7. **真图**（照片、插图、示意图、流程图、带表格线的表格图）：
   - 在图出现的位置，正文里单独写一行占位：`〔图：图的标题或一句话说明〕`
   - 同时在 figures 文件里登记这条 JSON（页内坐标是比例，0~1，[左, 上, 右, 下]，按你看到的整页画面估）：
     ```json
     [{"page": 61, "rect": [0.08, 0.55, 0.92, 0.85], "kind": "table", "title": "表3-1 要约与要约邀请的区别", "desc": "两张对比表格"}]
     ```
   - `kind` 取值：`table`（表格图）/ `photo`（照片插图）/ `diagram`（示意图流程图）。
   - 描述 `desc` 用一两句话说明图里是什么，方便读者判断要不要翻原图。
8. **整页空白**（空白页、扉页只有几个字）：也要写 `〔页N〕`，下面照实写那一两个字，或写一行「〔空白页〕」。

## 输出文件（三个都要写，没有内容就写空文件）

| 文件 | 内容 |
| --- | --- |
| `batches/bXXX.txt` | 正文（含每页 `〔页N〕` 行、`〔图：…〕` 占位行） |
| `batches/bXXX_notes.txt` | 脚注，每条一行 |
| `batches/bXXX_figures.json` | 真图 JSON 数组，无图写 `[]` |

## 写完自查（30 秒）

- [ ] 每张图都有 `〔页N〕` 行，页号连续且递增，一张不缺
- [ ] 章节标题都在正文里单独成行
- [ ] 没有 `□`、没有「看不清」、没有烂尾的半句
- [ ] figures.json 里的 page 都在本批页号范围内

完成后只回报一行统计（例：`b007 完成 正文10340字 脚注6条 图2张`），**不要把任何正文粘贴到对话里**。
