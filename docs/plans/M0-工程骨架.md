# M0 计划案：工程骨架（可构建的空壳 APK）v2

> 目标：建立 Android 工程，空壳 App 能构建出 APK 并可安装启动：底部导航（书架/复习/设置）+ 主题 + Room 空库 + Navigation 骨架。不包含任何业务功能。
> v2 修订：依评审意见修正依赖坐标显式版本、改用本机已缓存版本组合、补齐 Robolectric 联网对策与 wrapper 来源。

## 1. 目录结构

```
Studying with friend/            ← 工作区根（文档在 docs/）
  android/                       ← Android 工程根
    settings.gradle.kts
    build.gradle.kts
    gradle.properties
    local.properties             ← sdk.dir=E:\engine\androidstudioSDK（仅本机）
    gradle/wrapper/gradle-wrapper.properties + gradle-wrapper.jar
    gradlew.bat / gradlew
    app/
      build.gradle.kts
      proguard-rules.pro
      src/main/AndroidManifest.xml
      src/main/java/com/studyfriend/app/

        ui/theme/{Color,Theme,Type}.kt   ← Material3，护眼米白底+暖色主色（读书氛围）

      src/main/res/              ← 图标(自适应)、strings、themes

```

## 3. 实现要点
- Room 先建 `StudyDatabase`（version=1，仅 `SettingEntity` 一个真实表，保证建库路径被冒烟测试覆盖；其余 DAO 后续里程碑增量加入并升版本/迁移）。
- 主题：暖米白 `#FAF6EF` 底、主色暖橙棕 `#B0713A` 系、深色模式同源色板；Type 默认 + 加大正文行高。
- 底部导航三 Tab：书架/复习/设置，空态文案占位。
- Robolectric 测试基线（本机从未跑通过，按评审对策配齐）：
  - `testOptions { unitTests { isIncludeAndroidResources = true; all { it.systemProperty("robolectric.dependency.repo.url", "https://maven.aliyun.com/repository/public"); it.systemProperty("robolectric.dependency.repo.id", "aliyun") } } }`（**镜像必须走 JVM 系统属性**——robolectric.properties 只承载 @Config 字段，dependency.repo.url 写在里面会被静默忽略，评审反编译 4.14.1 证实）
  - `@Config(sdk = [34])` 锁 SDK 档位（platform android-34 已装且 robolectric 对 34 支持成熟）
  - `app/src/test/resources/robolectric.properties`：仅 `sdk=34`

## 4. 验证（M0 完成标准）
1. `gradlew.bat assembleDebug` 成功产出 app-debug.apk（记录大小）。
2. `gradlew.bat testDebugUnitTest` 通过（Robolectric 冒烟：Room 建库 + Setting 读写）。**若 android-all 下载失败**：降级方案=把该冒烟改为纯 JUnit 的 JSON 工具测试 + 把 Room 建库验证推迟到有真机/模拟器时；并在 README 记录。
3. `aapt dump badging`（build-tools/35.0.0）核对包名/minSdk/targetSdk/权限（仅 INTERNET）。
4. 构建命令与 JDK/SDK 环境变量写法写入 README（照 Studying-helper 的 JAVA_HOME/GRADLE_USER_HOME 经验）。

## 5. 风险（如实版）
- **联网补包**：AGP/Kotlin/Room/coroutines/serialization/activity/lifecycle/core/navigation/BOM/robolectric 均在缓存，但 compose 传递依赖（foundation/material3 具体小版本、material-icons 等）未必全量缓存，首次构建会联网补少量包；阿里云/google 双源兜底，失败重试。
- **android-all 大包**（Robolectric 首跑下载 ~100MB）：已配阿里云镜像；失败走第 4.2 降级方案。
- **空格路径**：若 aapt/AAPT2 异常 → junction `E:\engine\studying-friend`（总计划 §7）。
- wrapper jar 复制自 Studying-helper（同 Gradle 8.9），distributionUrl 保持华为云 URL 命中本机缓存；若 hash 未命中则接受 130MB 下载。
