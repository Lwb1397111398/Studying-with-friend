- [10 可执行性] run_ablation.py 在 `__file__` 位于 `.e2e/p6c/` 时计算 `_VENV = Path(__file__).parents[2] / ".e2e" / "p6a" / "venv"`——parents[2] 为仓库根 `<repo>`，拼接结果正确。但若 run_ablation.py 被移至其他目录（如 `.e2e/p6d/`），parents[2] 仍指向 `<repo>` 而非新的父目录，路径计算不变但依赖位置假设未文档化。 → 建议：在 run_ablation.py docstring 或注释中明确声明「本脚本必须位于仓库根下 `.e2e/p6c/` 目录，依赖 __file__ 的 parents[2]=仓库根的相对定位」，避免路径被误移后静默失效。
