- [6 成本预算] 手机端 rec 单页耗时估计为 8-15s/页，区间跨度近 2 倍（1.875×），且标注为[推断]。虽声明'R2 触发线 5s 不因此放宽'，但 8-15s 的上界意味着极可能触发 R2（>5s），而预案（hybrid 小计划案）本身尚未量化——形成预算不收敛循环。 → 建议：将[推断]区间拆为保守/基线/乐观三值（如 8/11/15s）并标注各自假设条件；或补充 PC→手机倍率的历史实测数据（Phase 0 若有 det 阶段的 PC↔手机耗时对照，引用该倍率使推断可追溯）。
