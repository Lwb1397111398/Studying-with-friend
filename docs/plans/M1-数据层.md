# M1 计划案：数据层（Room 实体 / DAO / 迁移 + 单测）v2

> 目标：一次性落全部业务表（对应总计划 §4.4），提供 DAO 与关键查询，带迁移与 DAO 单测。UI 不动，仅 DB 装配处小改。
> v2 修订：按评审补 books.overviewJson（M6 全书总览落点）、chapters.gist/keyTermsJson（粗读要点落点）、FK 级联策略写死、ReviewItemDao 间隔推进、exportSchema=true + schema JSON 落盘、para_notes 可追溯字段。

## 1. 表结构（v2，新增表走 Migration(1,2) 显式 SQL；外键全链 CASCADE）

| 表 | 字段（除主键外 TEXT/INTEGER） | 索引/约束 |
| --- | --- | --- |
| books | id PK auto, title, author, sourceType(TXT/PDF/PASTE), filePath, status(IMPORTED/READY), totalChapters, **overviewJson**(M6 全书总览落点), createdAt, updatedAt | — |
| chapters | id PK auto, bookId FK→books CASCADE, idx, title, readState(NOT_READ/READING/DONE), **gist**(粗读章节要点), **keyTermsJson**(粗读术语表) | (bookId) |
| paragraphs | id PK auto, chapterId FK→chapters CASCADE, idx, text, role(BODY/FRONT), aiAction(NONE/SKIP/EXPLAIN/GROUP), groupId, why | (chapterId) + unique(chapterId,idx) |
| para_notes | id PK auto, chapterId FK→chapters CASCADE, paraIds(JSON数组), title, friendly, analogy, keyPointsJson, memoryHook, questionsJson, **model, promptVersion**(AI 产物可追溯), createdAt | (chapterId) |
| chapter_assets | **chapterId PK + FK→chapters CASCADE**（一章一份资产，直接以 chapterId 为主键，无自增 id——规避 @Upsert 对 UNIQUE(chapterId) 冲突回退 UPDATE-by-id 失效的坑）, summaryMd, mindmapTree, mindmapJson, memoryMd, chainMd, quizJson, model, promptVersion, createdAt | PK=chapterId，天然 unique |
| quiz_attempts | id PK auto, chapterId FK→chapters CASCADE, qIndex, answer, verdict(CORRECT/WRONG/PARTIAL), feedback, createdAt | (chapterId) |
| review_items | id PK auto, bookId **FK→books CASCADE**, chapterId **FK→chapters CASCADE**, title, intervalIdx, dueAt(epoch ms), done | **unique(bookId,chapterId,title)** 防章末包重生成时重复排期 + (dueAt) + (chapterId)（FK 索引，消 Room 警告） |

- **FK 策略写死**：全链 Room `@ForeignKey(entity, parentColumns=["id"], childColumns=[...], onDelete=CASCADE)`——删书自动清 chapters，删章自动清段落/讲解/资产/做题/复习项，杜绝孤儿行（Studying-helper 用事务显式删，本项目表少层级浅，CASCADE 更省心）。
- 时间戳 Long(epoch ms)；复杂结构存 JSON 字符串；除 settings 外所有 AI 产物表带 model/promptVersion。

## 2. DAO 与关键查询（标注 Flow / suspend）
- BookDao：`getAllFlow(): Flow<List<BookEntity>>`（书架，updatedAt desc）、insert/update/delete、`getWithProgress(bookId)`（书+章数+已读数，JOIN 投影）、`getOverviewJson/upsertOverviewJson(bookId,…)`
- ChapterDao：`byBookFlow(bookId)`（含 LEFT JOIN chapter_assets 的"已总结"标记投影 data class）、insert 批量、updateReadState、**updateTitle**（目录改名）、**updateAiGist(chapterId, gist, keyTermsJson)**（chapterId 已唯一，无需 bookId 限定）、**deleteByBook(bookId)**（目录重切用，事务内删章重插，段落等子表靠 CASCADE）
- ParagraphDao：`byChapterFlow(chapterId)`、批量 insert（重切前先 deleteByChapter）、**updateAiAction(id, action, groupId, why)**、**deleteByChapter(chapterId)**
- ParaNoteDao：`byChapterFlow`、insert、deleteForChapter
- ChapterAssetDao：`byChapter` + `upsert`（**chapterId 为主键，@Upsert 冲突即主键冲突 → UPDATE 必命中**，含 promptVersion/model 更新——需单测钉死 chapterId 不变且内容全量更新）
- QuizAttemptDao：`byChapter`、insert、`wrongByBook(bookId)`（错题本）
- ReviewItemDao：`dueCountFlow(now): Flow<Int>`（书架/首页角标）、`dueList(now)`、insert（onConflict=IGNORE 配合唯一约束）、**markResult(id, newIntervalIdx, newDueAt, done)**（记得→推进 1/3/7/14/30，忘了→intervalIdx 归 0、重新排期）

## 4. 仓库层轻封装
`BookRepository`（仅 DB 操作封装，不含 AI/解析逻辑）：Shelf/Reader 所需纯数据读写，返回 Flow + suspend。避免 ViewModel 直捅 DAO。

## 5. 单测（Robolectric 内存库 + MigrationTestHelper）
1. MigrationTest：MigrationTestHelper 跑 1→2，验证新表可插入读取。
2. DAO CRUD 冒烟：书→两章→若干段→updateAiAction→查询断言；删除书验证 CASCADE 清空子表。
3. 进度投影：2 章读 1 章 → getWithProgress 返回 1/2。
4. 复习：过期/未到期两条 → dueList 只返回过期条；markResult 推进与归零两种路径断言。
5. 错题本：1 对 1 错 → wrongByBook 只返回错题。
6. chapter_assets upsert：二次写入后行数仍为 1、主键 chapterId 不变，且 promptVersion/model/内容全量更新。
7. 章节已总结投影：有/无 chapter_assets 时投影字段正确。
