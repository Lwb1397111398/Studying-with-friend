### 超标归因（逐条 diff 定性，t3_diff.py + 高倍裁图确证）

1. **OCR 标点宽度归一（literal 超标主因）**：本书中文正文逗号/冒号/括号/分号=半角（高倍图确证），PP-OCR v5 mobile 中文词典系统性输出全角。p092/p122/p384 折叠宽度后 **CER=0**（正文字符识别零错误），p062 0.37%。→ 非识别能力问题，是后处理可修问题（P6b 可按行内中西文语境把全角映射回半角）。
2. **GT 侧宽度错（已按图修复）**：转写模型对西文脚注有全角先验（p032），已逐区修正；140dpi 下西文标点宽度人眼难逐字符判定，残留不确定性计入 literal。
3. **真实 OCR 字符错误（折叠后仍存）**：
   - 德文/英文小字弱：p032 脚注 t→l×10、f 漏读×2、ä→ü 等（punctfold 3.53% 主体）；p003「—→一」「d→l」。
   - 形近字：疵→症（p062/p247）、宪→光、页→贞（p032）、赔→賠（繁体，p062/p081/p247）。
   - 树状图页结构丢失：p081/p247 的竖排侧标「不完全给付（第227条）」漏读/错位 + 制表符树线（图形非文字，GT 已删）线性化顺序与 OCR 分行不一致 → 两页 fold 5.4/6.2% 超标主因。
4. **引注圈码**：已双侧隐去（strip_citations.py，R-CIP 正则含全角Ⅰ修复后 p003 假 diff 消除 3.98→2.35%）。

### 交叉验证（计划案 line54，降级口径）

同模型独立二次转写 p092：不一致率 **0/832=0.00%**（阈值 2%）→ GT 可复现，不触发全量复核。
（偏差记档：本机无第二厂商 vision 模型，降级为同模型重转，只检随机不一致；补偿=老板 8/8 人工核对已通过。）

### 2.5 fallback 重判与新口径（老板 2026-02-10 拍板）

老板决定：**「标点胖瘦不算错 + 树状图页特殊处理」**。按此重判：

1. **标点宽度**：punctfold 口径下 6 页全部 ≤3.53%（p092/p122/p384=0.00%、p062=0.37%、p092=0.12%、p003=2.71%、p032=3.53%）→ 判据①通过。P6b 实现：OCR 后处理按行内中西文语境把全角标点映射回原书半角（规则已在 gt_fix2.py 验证：中文正文半角、西文语境半角、树状图全角）。
2. **树状图页（p081/p247 型）处理方案**（老板要求「想个好法子」）：
   - **识别**：复用方向扫描投影特征（ratio≥0.381 的 SUSPECT 带）+ OCR 框几何（竖排侧标框高宽比>3、树线区文字密度低）做「图形页分类器」，命中即标记 pageType=diagram。
   - **处置**：diagram 页**不进 OCR 批量**，整页转现有视觉大模型转写兜底（与竖排书同一条降级路径，决策案已保留）；OCR 结果仅作对照不入库。
   - **依据**：p081/p247 的 punctfold 5.43/6.20% 主因是树线结构无法线性化（GT 与 OCR 行序天然不一致），非字符识别失败——nopunct 口径 p081 5.63%/p247 5.84% 同样受行序支配。视觉模型读图对树状图语义还原更好（P3b-1 目录视觉识别已验证该路径）。
   - 全本 461 页中此类页占比：方向扫描 SUSPECT+VERTICAL 复核确认含体系图页约 6 页（p081/p135/p219/p247/p266/p406 类），<1.5%，降级成本可忽略。
3. **判据①字面 No-Go 保留记档**（不撤销），本报告双口径并列。

## 六、耗时（判据③，OCR 推理与渲染分离计时）

### PC 参考（x86_64，rapidocr+onnxruntime）
- 渲染：0.05s/页（fitz 140dpi）；推理：5.03s/页均值

### 模拟器实测（JingBianAVD：pixel_6 / API 35 / x86_64 / **4GB RAM / 4 核** / WHPX；主进程 :poc 方案改主进程，onnxruntime-android 1.22.0，工件 poc_result_emulator.json）
- 模型加载：1.1-1.3s（det+rec 双 session）
- 每页 totalMs（pre+det+detPost+rec）：p003 2696（含 JIT warmup）/ p032 1563 / p062 1243 / p081 1665 / p092 1203 / p122 1162 / p247 1646 / p384 490
- **中位数 1.40s（8 页）/ 1.24s（剔除首屏 warmup 7 页）**；det 180-260ms、det 后处理 7-38ms、rec 258-1401ms（随框数）
- 内存：基线 PSS 180MB（冷启动未跑 OCR）→ 跑完驻留 PSS 388MB / RSS 506MB；**OCR 增量 ≈ +208MB PSS**（native heap 峰值 443MB，onnxruntime arena 不回收）；4GB 设备占比 ~12%，largeHeap 下无 OOM 风险
- **口径声明（计划案纪律）**：模拟器 x86 算力≠真机 ARM，判据③正式判定仍以真机为准（ARM 通常慢 1.5-2×，若真机中位 1.4-2s 落条件档→按 §5③ 条件通过处理）；本模拟器数据证明 onnxruntime-android 管线功能可行+提供量级参考。
