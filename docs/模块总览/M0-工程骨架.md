## 交付物
- Gradle 工程：AGP 8.7.3 + Kotlin 2.0.21 + Compose BOM 2024.10.01，minSdk 26 / targetSdk 35 / Java 17，单模块 `android/app`。
- `StudyApp`：持有 Room 单例（lazy）。
- `MainActivity` + `ui/nav/AppNav`：Scaffold + NavigationBar 三入口（书架 Shelf / 复习 Review / 设置 Settings），Routes 常量集中定义。
- `ui/theme`：Color / Theme / Type（Material3，平板适配的窄宽窗体类）。
- `ui/screens`：三个占位屏 + `EmptyState` 通用空态组件。
- `SmokeTest`：Robolectric sdk34，验证 Room 建库 + settings 写读。

## 构建要点（本机约束）
- JDK 用 Android Studio 自带 JBR（`org.gradle.java.home`）。
- 低内存配置：`-Xmx1536m`、Kotlin in-process 编译（`kotlin.compiler.execution.strategy=in-process`）、`parallel=false`、`workers.max=2`、构建一律 `--no-daemon`。
- `GRADLE_USER_HOME=E:/engine/gradle-home`（英文路径副本，规避中文用户名导致测试 worker 类加载失败）。
- Robolectric 镜像走 JVM 系统属性（`robolectric.dependency.repo.url`，阿里云）。
