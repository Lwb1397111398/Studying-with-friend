## 数据模型（Room v7，全链 FK CASCADE，时间戳 epoch ms）
| 表 | 主键 | 说明 |
| --- | --- | --- |
| settings | key(TEXT) | 键值配置（M3 存 AI 地址/Key/模型名）；**v7 消费方增加**：`read_font_size`(14-30 无级)/`read_line_height`(1.4-2.2)/`theme_mode`(system/light/dark)/`tts_rate`(0.5-2.0)/`review_reminder` |
| books | 自增 id | 书元数据；`overviewJson` 是 M6 全书总览落点；**v7 加列** `lastReadChapterId`/`lastReadAt`（进阅读页即 markReading 记「最近在读」——书架继续读入口与 lastReadAt DESC 排序数据源，旧行 NULL 沉底回退 updatedAt） |
| chapters | 自增 id，FK→books | 目录；`gist`/`keyTermsJson` 是粗读章节要点；**v7 加列** `lastReadParaIdx`（0-based paragraphs.idx——滚动停止后写库，重进恢复；存段 idx 而非行下标，图行混排/段落重排不漂移） |
| paragraphs | 自增 id，FK→chapters，unique(chapterId,idx) | 段落；`aiAction`(NONE/SKIP/EXPLAIN/GROUP) 是粗读三态决定；`pageNo`(Int?) 段首页码（P3b-2，跨页并段取首页，TXT=null）；**v7 加 `searchInBook`**（LIKE 全书搜索 join chapters 带章名，pattern 经 escapeLikePattern 转义 %_\ + ESCAPE '\'，limit 上限 UI 传 200） |
| para_notes | 自增 id，FK→chapters | 段落讲解（paraIds JSON 数组，可覆盖多段） |
| chapter_assets | **chapterId 即主键**，FK→chapters | 章末资产一份（总结/导图树/记忆/串联/自测）；主键设计规避 @Upsert 冲突回退坑 |
| quiz_attempts | 自增 id，FK→chapters | 做题记录（CORRECT/WRONG/PARTIAL） |
| review_items | 自增 id，双 FK，unique(bookId,chapterId,title) | 间隔复习排期；IGNORE 防重排期，markResult 推进/归零；dueCountFlow 也是 v7 复习提醒 Worker 的数据源 |
| vision_queue | 自增 id，unique(bookId,pageNo)，FK→books | OPT-F 视觉后台队列（status PENDING/DONE/FAILED + attempts + **v6 `lowQuality`**）；删书 CASCADE |
| figures | 自增 id，FK→chapters | **P4-A 示意图**（pageNo/ordAfterPara/bboxY0/seqNo/file/width/height/format/md5/createdAt）；删书 CASCADE |
| bookmarks | 自增 id，**双 FK**→books+chapters | **v7 新表**：书签锚到一个自然段（chapterId+paraIdx），`preview` 冗余存段前 40 字（展示免 join paragraphs；段落重建后 preview 保底可读）；删书/删章 CASCADE |
| qa_history | 自增 id，FK→books | **v7 新表**：随手问历史（chapterId **故意不建 FK**——章目录重切后历史应存活到删书为止；chapterTitle 写入时冗余）；question/answer/createdAt；每书保留最近 50 条（insert 后 trim） |
