## 数据模型（Room v6，全链 FK CASCADE，时间戳 epoch ms）
| 表 | 主键 | 说明 |
| --- | --- | --- |
| settings | key(TEXT) | 键值配置（M3 存 AI 地址/Key/模型名） |
| books | 自增 id | 书元数据；`overviewJson` 是 M6 全书总览落点 |
| chapters | 自增 id，FK→books | 目录；`gist`/`keyTermsJson` 是粗读章节要点 |
| paragraphs | 自增 id，FK→chapters，unique(chapterId,idx) | 段落；`aiAction`(NONE/SKIP/EXPLAIN/GROUP) 是粗读三态决定；`pageNo`(Int?) 段首页码（P3b-2，跨页并段取首页，TXT=null） |
| para_notes | 自增 id，FK→chapters | 段落讲解（paraIds JSON 数组，可覆盖多段） |
| chapter_assets | **chapterId 即主键**，FK→chapters | 章末资产一份（总结/导图树/记忆/串联/自测）；主键设计规避 @Upsert 冲突回退坑 |
| quiz_attempts | 自增 id，FK→chapters | 做题记录（CORRECT/WRONG/PARTIAL） |
| review_items | 自增 id，双 FK，unique(bookId,chapterId,title) | 间隔复习排期；IGNORE 防重排期，markResult 推进/归零 |
| vision_queue | 自增 id，unique(bookId,pageNo)，FK→books | OPT-F 视觉后台队列：每可疑页一条任务（status PENDING/DONE/FAILED + originChars + attempts）；删书 CASCADE；**v6 加 `lowQuality`(默认 0)**：入队时由 ImportViewModel 按第一道闸放行页标记，VisionWorker 第二道闸凭它放行低质量图页的视觉转写（防御锚定改写，双闸口径统一） |
| figures | 自增 id，FK→chapters，Index(bookId)/Index(chapterId) | **P4-A 示意图**：pageNo(1-based)/ordAfterPara(页内锚，0-based，-1=页首前)/bboxY0(同锚次级排序)/seqNo(全书唯一，阅读页角标「图 N（p…）」)/file(相对路径 `figures/{bookId}/p{页}_f{序}.{png|jpg}`)/width/height(占位防跳动)/format/md5(落盘字节摘要)/createdAt；删书 CASCADE |
