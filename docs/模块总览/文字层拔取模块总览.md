# 文字层拔取模块总览

## 模块职责

对自带文字层的 PDF，直接按视觉阅读序抽取正文、脚注、插图，零视觉 API 调用；同时修 OCR 文字层的系统性错误，并把图示/表格乱码区换成图占位。

## 运作流程

1. `cmd_pull` 打开 `manifest.src_pdf`，对每一页调用 `_page_lines(page)`：
   - `page.get_text("dict")` 取所有文本行；
   - 若 `page.rotation != 0`，用 `page.rotation_matrix` 把行/span 的 bbox 变换到显示坐标（旋转页的文字在未旋转画布里是竖条，不变换必然乱序）；
   - 按 bbox **垂直重叠 ≥45% 行高**聚成视觉行（不再用 y0±2pt，引号/上标碎片不会被拆行）；
   - 行内按变换后的 x 排序，横向间隙 <4 字号直接拼接。
2. 全书统计正文主字号：中带区（0.10H~0.85H）按字数加权众数 → `gbody`。
3. 全书统计**重复书眉**：同一行（去掉数字与空白后）在 ≥3 页的 y1≤0.13 处出现 → `furniture`，抽页时整行丢弃。解决「第九章…形成481诉人犹复提起上诉…」这类书眉与页首正文粘连。
4. `_pull_page(page, fitz, body_size, lines, furniture)` 逐页处理：
   - 丢页眉/页脚/页码；剥离开头 1~3 位页码；
   - 页脚小字号（y0>0.72 且 size<正文×0.88）与正文后大间距（>2.2 倍字号）之后的行归入脚注；脚注按 y0 排序；
   - `_detect_fig_bands` 找图示/表格垃圾区（`｛｝＼｜〜` 等稀符号、密集冒号、多碎片行），并按上下相邻的短图注扩展矩形；
   - 纯垃圾 band（无正文句）整块删除，登记 `figs`（`from_pull=True`，desc 为占位）；混正文的 band 不删，整页标 `needs_vision`；
   - 索引/年表页（≥10 行、半数行含 ≥3 个数字）标 `needs_vision`；
   - 整页繁体字形（`_TRAD_ONLY` 中 ≥3 字）标 `needs_vision`；
   - 段落重组：标题（`CH_RE`/`SEC_RE`/字号 ≥正文×1.15）独立成段；行首缩进 >1.4 倍字号开新段；
   - 正文/脚注统一跑 `_fix_quotes(_fix_ocr_text(...))`；
   - 图占位行按图 rect 的 y0 插入对应段间；返回 `first/last` 行属性供跨页缝合。
5. 跨页缝合：下页首行顶格且非标题、上页末行非标题时，把下页首段拼回上页末段（修「请求|权基础」）。
6. 写批文件 `batches/bXXX.txt`（每页 `〔页N〕` + 段间空行）、`_notes.txt`、`_figures.json`；`b["needs_vision"]` 记待视觉复核页，`b["thin_pages"]` 记图版页。

## 入口文件

- `bookocr.py`：`cmd_pull`、`_pull_page`、`_page_lines`、`_detect_fig_bands`、`_embedded_fig_rects`、`_fix_ocr_text`、`_fix_quotes`、`_running_norm`、`_TRAD_ONLY`
- 配置：`config.json` 的 `route=pull-first|pull-only`

## 对外接口 / 被谁调用

- CLI：`python bookocr.py pull <书名>`
- 被 `cmd_reocr --exact` 复用：非目标页现场调用 `_pull_page` 重抽，保证只重识别点名页、不放大识别量。

## 依赖的上游模块

工程与状态（manifest、页范围）；下游是质检与修复（check/qa 决定哪页需要 reocr）。

## 关键数据结构

- 视觉行：`{text,size,x0,y0,x1,y1,n_frag,max_gap}`
- 页结果：`{paras,notes,figs,chars,fig_area,needs_vision,first_*,last_*,page_left}`
- 图：`{page,rect:[l,t,r,b],kind,from_pull,title,desc}`
- manifest 字段：`furniture`（全书书眉）、`batches.*.needs_vision`、`batches.*.thin_pages`

## 已知坑与约束

- **扫描件的 OCR 文字层质量参差**：同一本书会混着出版社文字层与扫描 OCR 层（整页繁体、形近字成片、双栏交错、图示乱码）。pull 只能修可判定的部分，跑完必须 `qa`，坏页 `reocr --exact`。
- `_TRAD_ONLY` 是 zhconv 繁→简静态生成的 4056 字；简体正文误报率实测 0。不要在运行时依赖 zhconv。
- 千→于规则是「简体正文里千+汉字几乎必然是于」，只保留数字前缀（一千/两千/数千/成千/若千）和千字词后续字（千年/千元/千字/千军…）。
- `＠` 在句末/段首是脚注标记，删除；正文中的「微博＠北京大学」不动。
- 旋转页的 span 也必须按变换后的 x 排序，否则「第1201条」会被拆成「条第1201」。
- 图区上下扩展遇到正文行必须停，避免把正文句一起吃进图里。
- pull 会重建 `figures`，**跑 figure-desc 之后不要再跑 pull**，否则图语义退回占位。
