## 设计决策（与踩坑）

1. **单事务落库（评审中-1）**：三步写库原为独立挂起调用，写库窗口内取消可造成"作答被清而资产旧/资产新而种子缺"。包 `db.withTransaction` 后原子性保证全有或全无。测试期确认的框架行为：room-ktx 事务块内挂起恢复不响应取消标记（事务线程同步推进到底），故取消落在写库窗口实测总是完整提交，挂起点抛取消才整体回滚——两种情况均无中间态，测试断言原子性不变量（rolledBack || committed）而非特定分支。
2. **Key 失败给出真出路（评审中-2）**：keyIssue 按钮原 onClick=onStart（原地重跑必然再败），改为 onOpenSettings 真导航设置页；ChapterAssetsScreen 参数贯通 AppNav。
3. **produceState 线程纪律**：runner.state / tts.state 由后台任务线程写入，collectAsStateWithLifecycle 在 Robolectric AndroidUiDispatcher 的恢复链不切线程 → 快照写在 worker → CalledFromWrongThreadException（实际抓到过）。统一模式 `produceState { flow.collect { withContext(Dispatchers.Main) { value = it } } }`，两处（runState/ttsState）同款。
4. **现任守卫三 Runner 一致（评审低-7）**：CancellationException 分支原有 `coroutineContext[Job] === job` 校验，catch(Exception) 补齐（Summary/Note/RoughRead×2 四处）——stop/start 替换后旧 job 迟到异常不得刷掉新状态。
5. **force 死参数删除（评审低-8）**：SummaryPlanner.run 的 force 全程未引用（重生成实际按 `byChapter()!=null` 判定），Runner/UI 同步去掉；重生成语义集中在 planner 资产存在性判定。
6. **题卡状态跨版本隔离（评审低-2）**：rememberSaveable 键 ("quiz", qIndex) 与资产版本无关，重生成后旧 revealed/answerText 泄漏给新题——`key(asset.createdAt)` 包裹强制重建。
7. **TTS 状态机忽略晚到错误**：用户 stop 引发的合成取消会晚到 onError——依当前状态忽略（已回 Idle/Preparing 之外的 Error 不覆盖）；toggle 连点经 job!=null→stop 幂等；prepare 与 speak 之间补 ensureActive。
8. **stripFence 前缀剥法（评审低-11）**：```` ```json{...}``` ```` 单行无换行时 substringAfter('\n') 得空串必败触发无谓重试——改 removePrefix 链。
9. **KDoc 禁含 `*/` 序列**：注释里写"- 减号/星号/圆点列表"而非列举字符本身（提前终止注释编译错）。
10. **git bash 调 powershell**：`$_` 会被 bash 展开 → 写临时 ps1 文件执行。
11. **M4aUiSmokeTest 回归适配**：M5 总结入口按钮占一行纵向空间，小视口下 SKIP 行"已跳过"落出懒列表合成区——先 awaitText("普通段落正文") 等 Flow 首发射（滚动容器才存在），再 performScrollToNode(hasText("已跳过"))。**不能 setContent 后立即滚动**：段落 Flow 未首发射时 EmptyState 分支使 LazyColumn 不在语义树，performScrollToNode 找不到滚动容器。
12. **测试 fake 语义**：SummaryPlanner 无 chat 异常重试（解析失败才重试），GateTest 假 chat 恢复后必须正常返回 legalRaw（抛异常会直穿 Failed）；entered 信号消除"挂住资格错移"竞态（沿 M4b 决策 8）。
