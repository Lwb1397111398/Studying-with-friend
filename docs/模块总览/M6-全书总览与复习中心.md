## 设计决策（与踩坑）

1. **wrongAll 不过滤 verdict（计划评审 P0 修复）**：若 SQL 带 `WHERE verdict='WRONG'`，"先错后对"的 CORRECT 行被提前滤掉、题目永远出不了列——去重两步走必须在内存做：全量取回→按 (chapterId,qIndex) 分组取最新→过滤 WRONG。WrongAttempt 投影相应带 verdict/bookTitle 字段（实现期发现首版投影漏 verdict 编译报错补上）。
2. **复习评估按进页快照**（计划 §2.2）：ReviewSession 在点击行时一次性读资产固化；复习中重生成总结包不中途换题、不崩。
3. **章级一次推进**（不逐题 markResult）：逐题自评只攒 ReviewVerdict 列表，最后一题评完 aggregateVerdict→advanceReview→markResult 一次落库——评估中途取消/退出 = 零落库，下次该章仍在到期列表。
4. **总览覆盖语义**：saveOverviewJson 直接覆盖（M5 总结包要清空本章作答是因题目身份随版本失效；总览无关联作答数据，无需联动）。
5. **DAO 方法零新增复用**：落库复用 BookDao.saveOverviewJson（Daos.kt:64 已有，含 updatedAt 刷新）——计划评审 P1-1 定案，实现遵守；新增的只有查询方法（dueListWithBookFlow/dueCountByBookFlow/overviewJson 无 Flow，进页快照+Succeeded reload）。
6. **门控口径**：总览 CTA/入口按"已总结章 ≥2"（promptVersion==SUMMARY_VERSION 且 summaryMd 非空）而非"读过 ≥2 章"——未总结章进不了总览输入，生成了必然空洞（计划 §3.3/§10 登记）。
7. **produceState 一次性读 + Succeeded reload**：BookOverviewScreen 的 overviewJson 用 produceState(bookId, reload) 快照读；Succeeded 瞬态到达时 reload++ 重读——避免为单页新增 overviewJson Flow DAO（与决策 5 一致）。Succeeded→落库顺序由 Runner 保证（Succeeded 在 planner.run 返回后设置，落库已完成）。
8. **Runner 纪律照搬 M5**：OverviewRunner 与 SummaryRunner 逐行同构——join 自替换（start 捕获旧 job→cancel→join 后 tryBegin）、CancellationException/Exception 都加 `coroutineContext[Job] === job` 现任守卫、finally gate.end()；四任务共享一把 AiGate。
9. **Robolectric setContent 单次限制**（实现期踩坑）：`Cannot call setContent twice per test!`——总览页"先测 CTA 再测有 payload"的两段式方案作废，拆成两个测试（各自 setContent 一次）。
10. **onNodeWithText 默认完全相等**（实现期踩坑）：副文案是长句，断言传子串会超时——awaitText 帮手改 `substring = true`（超时时 dump 语义树辅助定位）。
11. **到期天数文案**：overdueDays = (now-dueAt)/DAY_MS，≤0 显示"今天到期"，>0 显示"逾期 N 天"；now 进页固化，跨天停留不翻转（M7 评估 tick 重算）。
12. **错题本进页快照**：wrongAll+逐章题干回查是 suspend 一次性加载（produceState null→列表），无实时性要求；题干回查结果按 chapterId 缓存在单次加载内。
13. **safeFileName internal 化**：总览导图导出 PNG 复用章末导图同款文件名清洗，ChapterAssetsScreen 的 private 函数改 internal 同包共享（唯一对 M5 文件的改动）。
14. **质检循环修复要点**（82→99）：到期列表 `distinctBy (bookId, chapterId)` 防御（同章重命名双行只显示一条，专测锁定）；runner.state 收集统一 produceState+withContext(Main) 纪律（M5 决策 3 回归）；会话状态全部 remember（临时评估不跨旋转）；落库挂 appScope 防切 Tab 丢推进；门控与 planner 前置同口径（promptVersion+assetSummaryPresent 双条件）；OverviewPlanner 先投影过滤候选章再逐章查资产（大书不再全书循环）；有 payload 时重新生成失败给对称错误行；overviewLoaded 两态消除进页闪 CTA；ReviewScreen 全部经 BookRepository。
15. **复审观察项移交 M7**：ChapterListScreen 收 roughReadRunner.state 仍是 collectAsStateWithLifecycle（M4a 既有，非 M6 引入）；overviewLoaded 的 remember 未带 bookId key（导航每 entry 新实例，风险极低）；候选章 >20 时逐章查询略超计划字面"≤20 次"（主键单行查，量级小）。
