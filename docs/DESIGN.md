# DESIGN.md — 读书搭子设计基准

> 打磨界面时先读这份。设计语言只有一个词：**书房**。像一间安静的书房，不像一个效率工具。

## 产品与用户

- 用户：法学生老板一个人（也面向同样的长期读书人），手机上读书、划词提问、章末复习。
- 气质：纸、墨、暖木。安静、大方、耐看；不要科技感、不要 SaaS 风、不要花哨动效。
- register：**product**（设计服务于阅读任务）。

## 色彩策略：Restrained（克制）

- 中性色全部向「暖纸/暖墨」色调偏移（绝不用纯黑 #000、纯白 #fff）。
- 主色一枚：琥珀棕（amber/bronze，书房台灯色），只用在主操作、选中态、进行中状态。
- 书架封面色板（8 组低饱和书房色）是唯一的「多色」区域，别的界面不许彩虹。
- 浅色 = 暖纸底（奶油微黄）+ 墨字；深色 = 暖墨底（黑棕）+ 米字。深浅共用同一枚主色。

## 字体与层级

- 系统默认字族即可，不引外部字体。
- 正文阅读字号用户可调（14–30sp），界面 chrome 层级靠字重与 1.125~1.25 比例的字号差，不靠颜色乱跳。
- 数字（统计、进度）用中号加粗，标签小字次级色。

## 形状与层次

- 圆角语言：卡片 16dp、按钮/胶囊 999dp（全圆）、输入 12dp，全局统一。
- 分组用「同底色卡片 + 12~16dp 间距」，不用细分割线当主层次；卡片不嵌套。
- 列表行内操作用轻量胶囊（小字 + 淡描边），大实心按钮只留给全页唯一主操作。
- 阅读页正文区是「纸」：无卡片、无描边，靠留白与字级。

## 组件词汇表（全 App 统一）

- 主操作：实心胶囊按钮（主色），每屏最多一个。
- 次操作：淡描边胶囊或文字按钮。
- 状态徽标：小圆角矩形（4dp 圆角），次级色底。
- 分段切换（Tab）：胶囊分段样式，选中=主色容器底，不用老式下划线 TabRow。
- 空态：图标 + 主色淡圆底 + 一句教用户下一步做什么的话；不许只有一行灰字。

## 动效

- 150~250ms，ease-out；只 convey 状态（展开/切换/完成），无装饰动画。

## 禁止

- 纯黑白、彩虹化非书架界面、左缘彩条、渐变字、玻璃拟态、hero-metric 模板、装饰性动效。
- 大实心按钮阵列（章目录页每行一个「粗读」大按钮 = 反例，已改）。
