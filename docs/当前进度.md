- **根因定位**（学伴真实文案是「本机没有可用的中文语音，无法朗读」）：①Manifest 缺 `<queries>` TTS_SERVICE 声明（targetSdk 30+ 包可见性，TextToSpeech 绑不上引擎必失败——听的同机可用正因它有此声明）；②`setLanguage(简体中文)` 返回值一票否决（国产引擎常返回 MISSING_DATA 但实际能读）；③初始化无超时。
- **全量单测 847 例全绿**（TtsPlayerTest 5→8 例：prepare 签名 String? + LOCAL 回落成功/双失败 2 新例；`testDebugUnitTest` exit 0）。
- **debug/release 双包构建通过**（debug 134.6MB / release 136.7MB；sherpa 官方 aar 经 pickFirst 保留其配套 ort，APK 增量约 +15MB；R8 补 `com.k2fsa.sherpa.onnx.**` keep）。
- **模拟器实测（离线朗读全链路跑通）**：设置页「朗读引擎」双 chip + 下载区正常；模型 205.3MB 全量下载完成（hf-mirror 直连，373 文件就绪判定全过；小文件串行实测 13 秒/个太慢已改 8 路并发）；切「离线模型」后阅读页朗读：模型加载→逐句合成→AudioTrack 实际出声（underrun 重启日志佐证）→chip 变「停止朗读」→句进度推进→自动滚动跟随高亮。
