# 当前进度

> 每次换窗/收尾时更新；git commit 记过程事实，本文件只放「现在到哪了」。最近一次：2026-10-24（KIT 成品书直入）。

## 当前目标与范围

老板痛点升级：App 内置识别（PP-OCRv5 本地推理）不准 → 干脆**电脑侧把书识别好再导入**。本轮把 bookocr-kit 改造成 agent 无关、全自动的识别台，并把**章界权威从手机端猜改为电脑侧定死**：kit 新增 `chapters` 切章对账命令 + `pack` 写 KIT 章表元数据块；App 新增 KIT 直入通道（KitBookParser 按章表切章，不猜）。老板拍板三条：①「AI 页页看」只用子代理但不限 ZCode（Qoder/反重力等免费额度均可）；②章界 AI 自动核对、无人工确认（人不一定在电脑前）；③导入确认页一键完成。

## 已验证结果及证据

- **kit 侧（2026-10-24，commit bb73e24 + 页标记补丁）**：
  - `chapters` 命令：程序切章（章号族+前/后置词族）→ 目录条目 difflib 对账（偏移众数换算印刷页码）→ 三类疑点（toc_miss/gap/thin）出裁决任务卡 → 纯文本子代理 `--apply` 吸收（ADD/DROP/IGNORE 持久台账）；无疑点自动跳过。
  - `pack`：txt 头部写 `〔KIT-书 开始〕{json:kit/title/pages/chapters[{t,p,lv,r,a}]}` 块；**保留〔页N〕页标记行**（App 端剥标记记 pageNo）；`--auto-chapters`/`--no-chapters` 可选。
  - `config.json` 五键（route/pages_per_batch/dpi/aivision_workers/chapter_review/output），init 快照进 manifest；SKILL.md/README 改 agent 无关版。
  - selftest.py **59 项断言 ALL PASS**（chapters 切章/对账/裁决、元数据块回读、config 兜底、页标记保留）。
- **App 侧（2026-10-24，本轮）**：
  - `KitBookParser`（data/importer/）：extract（元数据块提取，损坏/版本不认→null 回退通用解析）+ stripMeta + parse（章表锚定切章：anchor 前 8 字去空白宽松匹配+页号过闸+首章锚 miss 兜底从头收/其余跳章段落归前章；`〔图：…〕`→FIGURE、`〔脚注〕`→FOOTNOTE、pageNo 随〔页N〕落库）。
  - `DbValues.ROLE_FIGURE` + ReadStyles 次级样式 + 五处 AI/计数过滤（RoughReadPlanner ×2/SummaryPlanner/ReadScreen/ChapterTree）。
  - ImportViewModel 接线：loadFile TXT 分支检测+剥块、parse() 分流、parseNote 徽标「bookocr 成品书：章界已由电脑侧确认」、kitMeta 在换文件/粘贴/失败/reset 四处清理；reparse 对 KIT 书忽略 regex。
  - **单测 MEASURED**：`gradlew :app:testDebugUnitTest` 全量 **813 绿 +1 skipped**（+11 KitBookParserTest；build.gradle.kts 加 testImplementation org.json:json 顶 JVM stub）。
