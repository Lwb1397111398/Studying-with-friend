## 当前目标与范围

老板对识别质量的反馈：「章节划分可以，但每一部分识别做的不好，特别是图片识别」。本轮把插图链路全补齐：①pull 图占位行按 y 坐标插段间（不再页尾）+ 段间空行修分段；②新增 `figure-desc` 命令给 pull 图批量补语义（裁图+视觉 API 逐图问答）；③check rect 交叉校正（目测坐标对齐 PDF 精确坐标）；④pack 产出 **KIT 图包 zip**（章表+正文+96 张真图三件套），App 端 zip 直入图文混排。txt 直入无图 → zip 图包直入有图有语义，老板投诉五点全闭环。
